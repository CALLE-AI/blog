# CALL-E Blog

Static files for the public CALL-E engineering blog.

GitHub Pages publishes the contents of `docs/` from the `main` branch.

## Local preview

```bash
python3 -m http.server 8000 -d docs
```

Then open <http://localhost:8000/>.
